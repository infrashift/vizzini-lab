**GitHub resolve needs `contents: write`.** With the template's default
token permissions (`contents: read`, `pull-requests: write`), GitHub refuses
`resolveReviewThread` ("Resource not accessible by integration", run
20261112T130032Z: 13/15). With `contents: write` it succeeds (the run above).
Since that permission also lets the token push, the template keeps it out
and documents it as an opt-in; this test opts in.
